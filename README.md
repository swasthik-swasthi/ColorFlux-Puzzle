# 🎨 ColorFlux Puzzle

A fast-paced color matching puzzle game developed using Unity and C#.

## 📱 Play Store

https://play.google.com/store/apps/details?id=com.ssonicgames.colorflux

## ✨ Features

- Color Matching Gameplay
- Increasing Difficulty
- Score System
- Smooth UI
- Mobile Friendly
- Fast Reflex Challenge
- Simple Controls

## 🛠️ Built With

- Unity
- C#
- Visual Studio
